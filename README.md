
# 💾 Banking Operations Analysis

**SQL | Snowflake | Data Analysis**

---

## 📌 Project Overview

This project demonstrates SQL skills through simulated banking scenarios involving loan reviews, credit utilization, and financial reporting.

The analyses highlight practical applications of SQL, from retrieving and filtering records to performing calculations.

## 🛠️ Tools & Skills

**Tools:** SQL, Snowflake, GitHub

**Skills:** SELECT, WHERE, AND, IN, ORDER BY, LIMIT, calculated fields, and column aliases.
